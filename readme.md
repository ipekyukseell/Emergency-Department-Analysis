# Emergency Department Analysis

## Project Overview

This project analyzes emergency department data using Python, Pandas, NumPy, and Matplotlib.

The analysis focuses on patient density, waiting times, age groups, triage information, and time-based patterns in emergency department visits.

## Project Question

Can historical emergency department data identify peak congestion periods and support better staff allocation?

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib

## Data Analysis

The dataset was analyzed using Pandas and NumPy. The analysis includes:

- Patient density by hour
- Average waiting time by hour
- Triage analysis
- Daily patient density
- Age group analysis
- Day type comparison
- Top 10 busiest time periods
